# Social Network Analysis of Christopher Paolini on Bluesky

This project is a network analysis of Christopher Paolini’s presence on the decentralized social media platform Bluesky. The analysis was conducted using **Gephi** and follows the requirements of the *Social Network Analysis* coursework at Athens University of Economics and Business.

## 📌 Project Overview

This study explores the structure of Christopher Paolini’s digital network, examining connectivity, key influencers, and community structures. The dataset was processed and analyzed using **Gephi**, leveraging its visualization and statistical tools.

## 🔍 Analysis Breakdown

The study covers:
- **Graphical Representation**: Visualization of the network structure.
- **Basic Network Properties**: Number of nodes & edges, diameter, and path length.
- **Component Analysis**: Identification of weakly/strongly connected components.
- **Degree Measures**: Degree distribution and ranking of influential users.
- **Centrality Measures**: Betweenness, closeness, and eigenvector centrality.
- **Clustering Effects**: Average clustering coefficient, triadic closure, and clustering coefficient distribution.
- **Bridges & Local Bridges**: Identifying nodes connecting separate clusters.
- **Homophily**: Examination of network formation based on similarities.
- **Graph Density**: Measure of overall connectivity.
- **Community Detection**: Identifying modularity-based communities.
- **PageRank Analysis**: Influence ranking based on network connectivity.
